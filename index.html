01 / FULL-STACK WEB APP

GeoGuard

A fraud-detection dashboard that flags "impossible travel": two card transactions in places too far apart to reach in the time between them.

[Individual project] · [Your role, e.g., Full-stack developer]

  • React
  • TypeScript
  • Node.js
  • Supabase
  • OpenRouteService
HOW IT WORKS
An Express API pulls transaction data from Supabase and compares each transaction with the previous one. GeoGaurd calculates the geographic distance and available travel time between locations to determine whether the movement is realistic and flag potentially impossible travel.
TECHNICAL CHALLENGE
One of the biggest challenges was calculating realistic travel feasibility between transactions. I had to combine geographic distance, time differences, and different transaction scenarios while also generating believable synthetic data to properly test the system.
WHAT I LEARNED
I learned how the backend, database, and geographic analysis can work together to solve a real-world fraud detection problem. I also became more confident working with Express, Supabase, APIs, and testing, and learned how important realistic test data is when building detection logic.

02 / MULTIPLAYER AI GAME

Promptionary

A party game where one player describes a secret image, the other players guess what it shows, and AI redraws the description. Players score on accuracy, clarity, and speed.

[Team Project] · [Frontend Development & Product Design]

  • React
  • TypeScript
  • Tailwind CSS
  • Node.js
  • Express
  • Supabase
  • Gemini API
TECHNICAL CHALLENGE
One of our biggest challenges was keeping gameplay synchronized across multiple devices while coordinating AI-generated images, player guesses, and scoring. We also had to work around API rate limits and browser microphone restrictions to create a reliable experience.
OUTCOME
Built and deployed a fully playable multiplayer game in a single hackathon weekend. Through playtesting, we refined the guessing mechanics and gameplay flow based on real player feedback, making the experience more intuitive and engaging.
